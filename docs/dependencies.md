# External dependencies

G4Cosmic keeps downloaded third-party source trees out of the framework source tree. Installer scripts live in `scripts/`, and installed dependency trees live under `external/`.

```text
scripts/
├── install_cry.ps1
├── install_cry.sh
├── install_corsika8.ps1
└── install_corsika8.sh

external/
├── README.md
├── .gitkeep
├── cry/          # generated by install_cry.*; ignored by Git
└── corsika8/     # generated by install_corsika8.*; ignored by Git
```

## CRY

CRY is installed into:

```text
external/cry
```

Install from the repository root on Windows:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\install_cry.ps1
```

Install on Linux or macOS:

```bash
chmod +x ./scripts/install_cry.sh
./scripts/install_cry.sh
```

CMake builds CRY directly from `external/cry/src/*.cc`. If CRY already exists elsewhere, point CMake at it:

```bash
cmake -S . -B build -DCRY_ROOT=/path/to/cry
```

The CRY runtime setup file owned by G4Cosmic lives at:

```text
config/cry/cry_setup.txt
```

That file is copied beside the example executables at build time.

## CORSIKA 8

G4Cosmic does not link directly against CORSIKA 8. Batch mode calls a runner/wrapper that writes the G4Cosmic/CORSIKA text `.dat` interchange format.

The best-effort installer places CORSIKA 8 under:

```text
external/corsika8/src
external/corsika8/build
external/corsika8/install
```

Install from the repository root on Windows:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\install_corsika8.ps1
```

Install on Linux or macOS:

```bash
chmod +x ./scripts/install_corsika8.sh
./scripts/install_corsika8.sh
```

The bundled CORSIKA demo files live under:

```text
examples/corsika/
├── example_particles.dat
└── demo_external_corsika_runner.py
```

`demo_external_corsika_runner.py` is a toy runner used to test G4Cosmic plumbing. Replace it with a real CORSIKA 8 wrapper/converter when doing physical shower production.
